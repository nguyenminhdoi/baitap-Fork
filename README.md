# baitap-Fork

# BÀI TẬP THỰC HÀNH C

## Nội dung

Viết chương trình C quản lý danh sách sinh viên đơn giản.

Yêu cầu:

1. Khai báo cấu trúc SinhVien gồm mã sinh viên, họ tên và điểm trung bình.
2. Nhập thông tin 3 sinh viên.
3. Xuất danh sách sinh viên ra màn hình.
4. Tìm sinh viên có điểm trung bình cao nhất.
5. Biên dịch và chạy chương trình thành công.

## Quy định nộp bài

- Mỗi sinh viên làm bài trên repository Fork của chính mình.
- Lưu mã nguồn trong tệp `main.c`.
- Commit và Push mã nguồn lên GitHub.
- Tạo Pull Request gửi về repository gốc của giảng viên.
- Ghi rõ họ tên và mã sinh viên trong README.md.
